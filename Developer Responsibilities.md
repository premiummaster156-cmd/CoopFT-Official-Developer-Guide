# Developer Responsibilities

## Role purpose
Developers build custom Discord bots and agreed technical features requested through CoopFT. This is a specialist technical role only; it grants no moderation or administration permissions.

## Core responsibilities
- Review the full request and submitted answers.
- Clarify requirements before starting.
- Confirm scope, deliverables, constraints, and acceptance criteria.
- Build only agreed features.
- Use secure coding practices and protect customer data.
- Test commands, permissions, error handling, and important edge cases.
- Provide a clean source ZIP and setup notes.
- Communicate progress and blockers in the authorized project ticket.

## Not included by default
Hosting, deployment, 24/7 operation, ongoing maintenance, unrequested features, and unlimited revisions are not included unless Owner Rank explicitly approves a change.

## Customer communication
Be professional and realistic. Never claim a feature is complete before testing it. Never request tokens, passwords, or private API keys in plain ticket messages.

## Authority
Owner Rank confirms commercial terms and receives payments. Developers do not independently set binding prices, collect customer payments, or change the free-service policy.
